# Animal Adoption Database

## Overview
This academic project focuses on designing a relational database for an animal adoption organization. It manages information about animals, animal types, vaccination records, and adoption requests.

## Technologies
- Oracle SQL
- Oracle APEX (academic project)

## Database Structure
The database includes the following tables:
- `aTip` — animal types
- `aAnimal` — animal records
- `aVaccin` — vaccination records
- `aCerereAdoptie` — adoption requests

## SQL Concepts
- Table creation and relational database design
- Primary keys and foreign keys
- Data integrity constraints
- SQL data insertion
- Queries, joins, aggregation, and statistical reporting

## Project Scope
This repository documents the database schema, sample data, and SQL queries developed for an academic project. The original Oracle APEX environment is no longer available.
